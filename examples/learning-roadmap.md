# Learning Roadmap

A structured path through concept notes and papers, organized as a **spiral curriculum** with dependency ordering. Use the `guided-learning` skill to run sessions.

## How This Works

**Three passes, increasing depth:**

| Pass | Goal | Session Length | Paper Status After |
|------|------|----------------|-------------------|
| **Pass 1: Overview** | "What is this and why does it matter?" | ~20 min | `skimmed` |
| **Pass 2: Working Understanding** | "How does it work? Can I apply it?" | ~30 min | `read` |
| **Pass 3: Fluency** | "Can I write and argue with this?" | ~30-45 min | `deep-read` |

**Within each pass, clusters follow dependency order.** Each cluster builds on the previous. You need to understand the foundations before you can evaluate more advanced methods.
